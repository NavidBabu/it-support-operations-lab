# IT Support Operations Lab

A simulated enterprise IT-support project designed around the responsibilities of an Information Technology Student: Tier 1/2 support, hardware deployment, support-call logging, equipment audits, process documentation, and systems-support coordination.

> **Important:** All tickets, users, locations, serial numbers, asset tags, and change records are simulated for portfolio use. No employer or customer data is used.

## Project contents

- **IT Support Operations workbook**
  - support ticket log
  - asset inventory
  - hardware deployment tracker
  - equipment audit
  - system change log
  - knowledge base
  - KPI dashboard
- **PowerShell endpoint inventory / audit script**
- **IT support troubleshooting runbook**
- **Hardware deployment checklist**

## Skills demonstrated

- Tier 1 and Tier 2 support concepts
- Windows desktop support
- Microsoft 365 support
- PowerShell
- Basic hardware troubleshooting
- TCP/IP, DHCP, DNS and connectivity diagnostics
- Support-call logging
- Hardware deployment
- Equipment audits
- Change management
- Process documentation
- Customer service and escalation
- IT operations KPI reporting

## Interview explanation

I built this project to practice the complete workflow of an IT support student rather than only listing troubleshooting skills. I created a simulated ticketing environment, tracked hardware assets and deployments, built an equipment-audit process, documented system changes, and created reusable knowledge-base articles. I also wrote a PowerShell script to collect endpoint inventory and diagnostic information.

The goal was to show how good IT support combines technical troubleshooting with accurate records, clear communication, hardware control, process documentation, and consistent follow-through.
