# Hardware Deployment Checklist

## Receive / audit equipment
- Verify asset tag
- Verify serial number and model
- Confirm physical condition
- Record location and intended user
- Update inventory

## Prepare device
- Boot and verify hardware
- Apply Windows updates
- Confirm approved software
- Configure Microsoft 365
- Verify security controls
- Confirm network connectivity
- Test dock / display / peripherals

## User setup
- Confirm assigned user
- Prepare profile / approved access
- Confirm Outlook / Office sign-in
- Test printing or required site resources
- Confirm data / profile transfer where applicable

## Handoff
- User confirms login
- User confirms network access
- User confirms core applications
- Record handoff date
- Update inventory status to Assigned

## Post-deployment
- Close deployment task
- File shipment / equipment records
- Document exceptions
- Escalate unresolved issues
